POST /query_breakfast_right
用途：扫码后查询客户信息，以及当前是否允许完成早餐。
请求
{
  "order_code": "T202607010001",
  "card_no": "123456"
}
字段：
order_code  必填，订单号/导检单条码
card_no     可选，卡号；有就传，没有可不传
 
返回：允许早餐
{

字段说明
order_code
    订单号

card_no
    卡号

name_b64
    姓名，UTF-8 后 Base64

sex_b64
    性别，UTF-8 后 Base64

phone
    手机号，建议脱敏

avatar_b64
    可选。当前客户端暂时 bypass 此字段，不解析、不解码、不参与照片展示

avatar_url
    可选。当前客户端唯一使用的头像来源
    绝对 HTTP(S) 地址直接使用；相对地址按本次客户查询使用的后端 scheme、host、port 解析
    URL 图片异步加载，允许晚于客户基础信息显示

头像字段约束
    avatar_b64 与 avatar_url 均可缺失、为 null 或为空字符串
    当前即使两者同时存在也只使用 avatar_url
    URL 缺失、无效、不可达或内容不是图片时，审批弹窗保持占位头像
    头像是否存在、加载是否成功不影响剩余客户信息的独立解析和展示
    新扫码会替换客户模型并取消上一客户的 URL 图片请求，避免旧头像回灌

birth_date
    出生日期，yyyy-MM-dd

package_name_b64
    套餐名称，UTF-8 后 Base64

has_breakfast
    冗余字段，仅展示/调试用
    前端不要用它做业务分支

allow_breakfast
    唯一判定字段
    true  = 允许点击完成早餐
    false = 禁止点击完成早餐

breakfast_status
    0 = 未完成早餐
    1 = 已完成早餐

reason_b64
    不允许早餐的原因，UTF-8 后 Base64
    例如：无早餐权益 / 空腹血糖未完成 / 腹部B超未完成 / 已完成早餐
 
前端判断逻辑
只看 allow_breakfast 和 breakfast_status。
allow_breakfast = true && breakfast_status = 0
    完成早餐按钮可点击

allow_breakfast = false
    完成早餐按钮置灰
    展示 reason_b64 解码后的原因

breakfast_status = 1
    完成早餐按钮置灰
    显示已完成早餐
不要写成：
if has_breakfast == false
    ...
else if allow_breakfast == false
    ...
统一写成：
if allow_breakfast == false
    展示 reason
    禁用完成按钮
 
Kotlin 数据结构
data class BreakfastRightRequest(
    val order_code: String,
    val card_no: String? = null
)
data class BreakfastRightResponse(
    val code: Int,
    val msg: String?,
    val data: BreakfastRightData?
)
data class BreakfastRightData(
    val order_code: String,
    val card_no: String?,
    val name_b64: String?,
    val sex_b64: String?,
    val phone: String?,
    val avatar_b64: String?,
    val avatar_url: String?,
    val birth_date: String?,
    val package_name_b64: String?,
    val has_breakfast: Boolean?,
    val allow_breakfast: Boolean,
    val breakfast_status: Int,
    val reason_b64: String?
)
 
最终原则
后端负责判断为什么不允许早餐。
前端只展示原因，不拆业务。
前端只根据 allow_breakfast 决定按钮能不能点。
审批弹窗和客户基础信息立即显示，固定尺寸照片占位框独立异步加载 avatar_url；新扫码会取消上一客户的照片任务。
